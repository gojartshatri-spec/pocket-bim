# Pocket BIM

A lite ArchiCAD for phones: floor plans with walls, doors, windows, columns, slabs, roofs, stairs, furniture, zones and dimensions, several stories, and a live 3D view. Works offline once installed.

**Open it:** https://gojartshatri-spec.github.io/pocket-bim/

**Install on iPhone:** open the link in Safari, tap Share, then *Add to Home Screen*.
**Install on Android:** open the link in Chrome and tap *Install*.

Projects are saved on the device itself.
